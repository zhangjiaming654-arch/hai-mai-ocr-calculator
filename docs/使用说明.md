# 海迈取数计算器 · 使用说明

## 用途

在计价软件的「相同清单编制」界面里，框住屏幕上的数字，按你设定的下浮率，算出该填的价：

| 模式 | 框住什么 | 输出什么 |
|---|---|---|
| **主材单价** | 「控制单价」一个数 | 该填的**主材单价** |
| **调价** | 「控制单价」+「单价下浮」两个数（从左到右） | 「调整人材机」里该填的**定额系数** |

两种模式共用一个「下浮率」输入框。

## 怎么用（三步）

1. 双击桌面上的「海迈取数计算器」（蓝底虚线框 + ¥ 图标），或双击文件夹里的 `run.bat`。
   小窗口总在所有窗口上面。
2. 把窗口拖到计价软件表格上，**拖窗口里的蓝色取景框**对准要取的数字：
   - 拖蓝框的四个角 = 把框放大/缩小（可以缩到只剩一行、只框一列）
   - 拖蓝框的边框 = 整个框挪位置
   - 框外那层点状灰 = 「这一块不取」
   - 框里面是**真透明** = 数字看得清清楚楚，不会看错行（所以框内鼠标点不进去，挪框请拖边框）
3. 选好模式，点【识别】→ 结果框里只显示一个数。改下浮率会立即重算，不用重新识别。
   **结果会自动进剪贴板**：到计价软件里按 `Ctrl+V` 直接粘贴（多行时一次粘多行），关掉本窗口后也还能粘。

模式、窗口大小、取景框的位置和大小都会被记住；切换模式时取景框自动换成该模式的默认大小
（主材单价 80×48，调价 140×53），你也可以随时再拖。

## 下浮率怎么填（符号跟海迈一样）

| 你填 | 含义 | 海迈「单价下浮」列 |
|---|---|---|
| `−9` | 下浮 9% | −9 |
| `−9.68` | 下浮 9.68% | −9.68 |
| `9` | 上浮 9% | +9 |
| `0` | 不下浮 | 0 |

```
目标单价 = 控制单价 × (1 + 下浮率 ÷ 100)
```

## 两种模式的计算

### 主材单价模式

适用于「定额里只有主材、没有别的人材机」的情况：

```
综合单价 = 主材单价 × K
K        = (1+管理费率) × (1+利润率) × (1+税率)
         = 1.0679 × 1.06 × 1.09 = 1.23385166      （本工程取费口径）

主材单价 = 目标单价 ÷ K
```

例：控制单价 245.89，填 −9.68 → 目标单价 222.09 → 主材 180.00。

> 为什么是连乘放大：这套口径的**取费基数 = 人工费 + 材料费 + 机械费**，
> 主材（材料费）被管理费、利润、税金各乘一次，所以被放大 23.39%。
> 换工程改 `config.json` 里的 `mgmt_rate` / `profit_rate` / `tax_rate`。

### 调价模式

「调整人材机」填的是**定额系数**，对定额人材机等比放大，综合单价是线性的：

```
系数 = (1 + 目标下浮率/100) ÷ (1 + 当前下浮率/100)
```

例：控制单价 982.33、当前下浮 −36.94%、目标 −9%
→ `0.91 ÷ 0.6306 = 1.443`，在「定额 系数」里填 **1.443**。
（填 1.44 得 −9.19%，填 1.45 得 −8.56%。）

调价模式只用到两个下浮率，**与取费口径无关**，所以定额里还有人工/铁件/机械时用这个更准。

## 费率要改怎么办

用记事本打开 `config.json`，改 `mgmt_rate` / `profit_rate` / `tax_rate`（单位 %），存盘重开。
程序启动时会自检（245.89 填 −9.68 应得 180.00，且正数结果要比负数大），对不上会弹窗提醒。

## 小提示

- 取景框内透明穿透，挪框请拖边框、改大小拖四个角。
- 只认**大于 1 的正数**：负数（下浮率那种 −9.68）和合计列的杂讯会丢掉——下浮率请在输入框里填。
- 计价软件窗口必须真的显示在屏幕上（被别的窗口挡住、最小化都识别不到）。
- 框到多行会输出多行（每行一个结果）。
- 万一出错，日志在 `%TEMP%\hm_app.log`。
